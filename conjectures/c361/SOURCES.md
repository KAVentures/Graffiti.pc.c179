## Mathematical audit

Every support is forced by its adjacent leaf. For positive i, at least one non-support is forced. If gamma_t=i+1, the support set is independent and there is exactly one selected non-support x; every support is adjacent to x. The selected set induces a connected star. Each outside vertex has an attachment to this star by domination; two attachments or an outside edge would contradict acyclicity. Thus every outside vertex is a leaf. None attaches to x because x is not a support. If i=1 the tree is a star; if i>=2 it is a star whose outer vertices each have at least one new leaf. In each case the center is unique. Conversely in either family all supports and one additional vertex are sufficient, giving equality in gamma_t>=i+1. If i=0 the bound follows from gamma_t>=2 and |C|<=2. This proves the claimed inequality independently of the finite enumeration.
